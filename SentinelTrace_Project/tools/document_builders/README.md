# Optional document builders

These source scripts were used to generate the Word deliverables. They are kept outside the runtime code so the evaluator can focus on the application in `src/`, `web/`, `sample_data/`, and `tests/`.

They are not required to run SentinelTrace. If documents must be regenerated, use an environment with the `python-docx` package installed and ensure the output paths target the separate folders under `deliverables/`.
